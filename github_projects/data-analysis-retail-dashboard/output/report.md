# Retail Sales Analytics Dashboard Report

## Executive Summary

The cleaned dataset contains 369 completed retail orders. Total revenue is $96,222.20, total profit is $39,198.75, and the strongest category is Audio.

## Data Cleaning

- Removed cancelled and returned orders from KPI calculations.
- Standardized date, region, channel, and customer segment fields.
- Created revenue, profit, month, and average order value metrics.
- Exported clean tables for Excel, Power BI, and Tableau.

## Dashboard Findings

- Best category by revenue: Audio ($33,732.30).
- Best region by revenue: North ($26,187.90).
- Average order value: $260.76.
