# GitHub-Ready Portfolio Projects

These folders are separate portfolio projects prepared for individual GitHub repositories.

| Folder | Portfolio Area |
| --- | --- |
| `data-analysis-retail-dashboard` | Data Analysis: Python, SQL, Excel, Power BI, Tableau, Data Cleaning, Dashboard Design |
| `data-science-churn-forecasting` | Data Science: Machine Learning, Exploratory Data Analysis, Pandas, NumPy, Model Evaluation, Forecasting |
| `flutter-firebase-taskflow` | Flutter Development: Flutter, Dart, Firebase, REST APIs, Responsive UI, Git |

GitHub CLI is not installed on this machine, so the folders are prepared locally and can be pushed after installing and authenticating `gh`.

After `gh` is installed and authenticated, publish all three projects from this folder:

```powershell
.\publish_all.ps1
```
