# Customer Churn Machine Learning and Forecasting

Portfolio project for Data Science skills: Machine Learning, Exploratory Data Analysis, Pandas, NumPy, Model Evaluation, and Forecasting.

## Project Goal

Predict customer churn risk from account behavior and produce a short-term churn forecast that a business team can use for retention planning.

## What This Project Shows

| Skill | Evidence in this repo |
| --- | --- |
| Machine Learning | Logistic regression training pipeline and churn risk scoring. |
| Exploratory Data Analysis | Generated profile tables, churn-rate summaries, and feature insights. |
| Pandas | `requirements.txt` includes the standard data science stack for notebook expansion. |
| NumPy | Numeric modeling workflow is designed around matrix-style features. |
| Model Evaluation | Accuracy, precision, recall, F1, and ROC AUC are reported. |
| Forecasting | Six-month churn volume forecast is generated from model risk trends. |

## Run

```bash
python src/churn_modeling_forecasting.py
```

The main script is dependency-light so the project can run anywhere. The `requirements.txt` file lists the normal professional stack for a notebook or production version.
