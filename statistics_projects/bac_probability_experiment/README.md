# BAC Probability and Hypothesis Testing Experiment

Small experimental statistics project using the OpenIntro beer and blood alcohol content dataset.

## Main Skills

- Descriptive statistics
- Inferential statistics
- Hypothesis testing
- Simple regression
- Probability
- Research methods

## Run

```bash
python statistics_projects/bac_probability_experiment/analyze.py
```

The report is generated at `output/report.md`.
